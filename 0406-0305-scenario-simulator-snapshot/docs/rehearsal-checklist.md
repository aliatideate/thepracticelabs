# Full multi-person rehearsal checklist

Run after Steps 1–7 on **staging**, then **production**. Use sessions **created through Creator**, not legacy `/demand` or `/mart`.

## Prep

- [ ] Staging deploy is current tip of `main`
- [ ] Log into Creator on staging
- [ ] Create a non-Unilever client (e.g. “Rehearsal Co”)
- [ ] New session: Demand Spike with renamed company/logo
- [ ] New session: Week in the Field with renamed chain/branches
- [ ] Open facilitator board + regenerate co-facilitator `?token=` link

## During (30 min)

- [ ] Six or more windows join as different teams (mix of both sessions if time)
- [ ] Refresh mid-activity on a player window
- [ ] Refresh mid-activity on the facilitator board
- [ ] Facilitator (logged in) and co-facilitator (`?token=`) on the board together
- [ ] Attention / nudge if available
- [ ] Submit / reach reveal on enough teams
