Please add a new Moderator View prototype to the existing Scenario Simulator project.

This should be a front-end-only prototype view, using the same visual language, components, layout patterns, colors, typography, cards, status pills, and header treatment already used in the participant/team view.

Do not rebuild the participant flow. Add a separate moderator dashboard route/view that can be accessed from a simple route, tab, or temporary button, for example:

- /moderator
- ?view=moderator
- or a “Moderator View” button in development mode

The goal is to show what the workshop facilitator/moderator would see while five teams are working through the same scenario in breakout rooms.

---

## Overall purpose

The moderator dashboard should help the facilitator see, at a glance:

1. Which workshop and scenario are currently active
2. Where the group is in the workshop exercise
3. Where each team is in the simulation journey
4. Which stakeholder each team interviewed
5. Which evidence source each team selected
6. Which teams are stuck, slow, active, or submitted
7. What useful insights are emerging for the debrief
8. How the moderator can send guidance or request access to a team’s workspace

This view should feel like a live workshop control room, not a complex analytics dashboard.

---

The participant journey currently includes steps like:

## Team card visual behavior

Status colors:

- Complete / submitted: green
- On track: yellow or neutral
- Slightly slow: orange
- Needs attention: red/orange
- Not started: muted grey/purple

Each team card should have a clear status pill.

The current step should be visually highlighted.

The progress indicator can be either:
- small horizontal step chips
- or a segmented progress line

Preferred:
Use compact step chips:
Brief · Stakeholder · Interview · Evidence · Define · Submit

Completed steps should show a check or filled state.
Active step should use yellow/orange.
Future steps should be muted.

# Right Panel 2: Send Note

Title:
“Send Note”

Subtitle:
“Send a guidance message to one team or all teams.”

Fields:
- Recipient dropdown:
  - All Teams
  - Team 01
  - Team 02
  - Team 03
  - Team 04
  - Team 05

- Message textarea

- Quick templates as selectable chips/buttons:

1. “Time nudge”
   Message:
   “You have 10 minutes left. Start moving toward your problem statement.”

2. “Problem framing reminder”
   Message:
   “Don’t solve yet. Focus on defining the problem worth solving.”

3. “Evidence reminder”
   Message:
   “Use both your interview and evidence source before writing your statement.”

4. “Team discussion prompt”
   Message:
   “Make sure everyone contributes before submitting.”

5. “Disagreement prompt”
   Message:
   “If your team disagrees, capture the disagreement — it may be useful in the debrief.”

Button:
“Send Note”

Interaction:
- Clicking a template should populate the message textarea.
- Clicking Send Note should show a small success state/toast:
  “Note sent to [recipient].”
- Add a new item to the live activity feed if possible:
  “Moderator note sent to [recipient].”

This can all be local state only.
