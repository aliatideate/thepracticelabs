Please add contextual, dismissible facilitator notes/tooltips to selected screens in the prototype.

The goal is to make the Simulation Studio experience feel connected to the live workshop, rather than feeling like a separate self-contained app. These notes should feel like short messages from the workshop moderator/facilitator, guiding the team at key points in the journey.

Do not rebuild the prototype. Add this as a lightweight UI layer on top of the current screens.

---

## General behavior

Add a reusable component called something like:
- FacilitatorNote
- ModeratorNote
- WorkshopNudge

The note should:
- Appear on specific screens only
- Be dismissible with an “X” or “Got it” control
- Stay visually secondary, not block the main flow
- Be readable but compact
- Feel like a live facilitator message
- Match the current dark Ideate internal tools visual style

Suggested styling:
- Small floating card or inline callout
- Dark translucent background
- Thin yellow/orange or purple border
- Small facilitator/moderator icon or label
- Label: “Facilitator note”
- Body text below
- Optional small timestamp-style label like “Workshop guidance”
- Dismiss icon in top-right

Placement:
- Prefer top-right of the main content area where there is space
- On narrower screens, place below the title/subtitle
- Do not cover primary CTAs, question options, typed interview responses, or the insights cards
- The note should not cause major layout shifts if dismissed

State:
- Use local state to track dismissed notes.
- Dismissing a note should hide it for that screen.
- It is okay if dismissal resets on page refresh.
- If the user navigates away and comes back, either behavior is acceptable:
  - note remains dismissed during the session, or
  - note appears again
Preferred: keep it dismissed during the session.
